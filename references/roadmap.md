# Roadmap

## Phase 1（骨架，已完成 ✅）

零依赖 CLI、离线可信注册表 `registry.json`、pytest 测试套件。

## Phase 2（智能层，已完成 ✅）

语义匹配（轻量离线，不依赖 embedding）、技能质量评级（七维含引用完整性，0-100）、
冗余检测（区分重复安装 vs 功能冗余，中文去停用+bigram 降误报）、瘦身建议（只读）。

## Phase 3（硬核安全 + 全生命周期，已完成 ✅）

AST 级安全分析、在线目录 sync + 离线缓存、环境感知引用校验、
`update` / `uninstall`（回收站可还原）/ `clean-dupes`、`discover` 榜单 + 跨源版本仲裁。

## Phase 4（对标头部看齐，已完成 ✅）

红旗补齐 8 项、四级风险分类、权限清单、信任层级 5 级、frontmatter 标准化、
渐进式披露 `references/` 拆分、市场标准卡 `skill-card.md` + 隐私条款。

## Phase 5（可选演进）

1. **已装技能使用追踪**：接入宿主使用信号，判断哪些真正被用过，定期给"可卸载"建议。
   当前 `prune` 仅基于静态信号，已诚实标注非真实使用追踪。
2. **语义匹配升级**：当前为轻量同义词词典（离线、零依赖）；若宿主提供 embedding API，
   可升级为真实语义向量召回。CLI 仍只提供客观数据与校验器，不假装做 NLP。
3. **生态体检报告**：一键生成「本地技能生态体检」（安全 / 质量 / 冗余 / 版本陈旧 /
   许可证合规）Markdown 报告。
4. **多源许可证合规扫描**：自动识别已装技能的许可证，标出与项目许可冲突者。

## 已知限制（诚实标注）

- `prune` / `redundancy` 基于**静态信号**（描述相似度、质量评级），**不是**真实使用追踪。
- 语义匹配为**同义词词典召回**，非 embedding 语义向量。
- 安全扫描为**静态分析**：无法覆盖运行时行为、动态加载、条件触发的恶意逻辑。
  扫描干净 ≠ 安全保证，须结合人工审阅。
- `registry.json` 为**手工精选**（15 条），downloads 为 `null` 表示"未核实"，不编造数据。
  全量目录靠 `sync` 拉取。
